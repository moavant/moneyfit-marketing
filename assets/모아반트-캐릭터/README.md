# 모아반트 캐릭터 에셋

블로그·SNS 카드뉴스 등 이미지 제작 시 사용할 모아반트 마스코트 캐릭터(파란 다람쥐/여우 캐릭터, 흰 배·귀 안쪽, 브랜드 블루 톤) 이미지 모음. 원본 출처: `~/Downloads/characters2`(2026-08-16 사장님 제공, 그대로 복사).

## 구성

- `sheet1_*.png` (26장), `sheet2_*.png` (28장), `sheet3_*.png` (29장) — 세 장의 스프라이트 시트에서 캐릭터 한 컷씩 잘라낸 개별 PNG. 표정·포즈가 시트별로 다양함(인사·놀람·앉기 등).
- `s1_*.png` (18장) — `sheet1_*`과 같은 컷 번호 대역이지만 **전부 동일 파일은 아님**(파일 비교 결과 11장은 sheet1과 다른 버전, 7장은 동일). 어느 쪽이 최종 버전인지 확인 안 됨 — 실제 사용 전 원하는 버전을 골라야 함.
- 전부 투명 배경 PNG로 보임(육안 확인, 별도 처리 없음).

## 사용 시 참고

- 아직 특정 이미지 생성 스크립트(`moavant-blog/scripts/generate-hero.mjs` 등)에 자동 연결돼 있지 않다 — 이번 라운드는 폴더 정리·복사까지만. 특정 글에 특정 캐릭터를 어떻게 매칭할지(랜덤/카테고리별/고정 등)는 별도 결정 필요.
- 원본은 `~/Downloads/characters2`에도 그대로 남아 있음(이 폴더는 복사본).
